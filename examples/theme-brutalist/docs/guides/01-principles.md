# Principles

The brutalist theme is direct by design. Decoration is built from structural
elements—borders, labels, grids, and type—rather than soft depth effects.

## Show the structure

Page columns are separated with heavy rules. Navigation states look attached
to the underlying grid instead of floating above it.

### Use real hierarchy

Weight, case, and scale clearly distinguish titles, sections, and labels.

## Spend color deliberately

Signal color marks the few things that deserve immediate attention: the
project mark, active navigation shadow, heading bars, and callouts.

> Strong visual language works when every element follows the same rules.

## Stay functional

The treatment is expressive, but the interaction model remains Makit's:
semantic navigation, JS-free disclosures, keyboard-friendly search, and
responsive reading layouts.
