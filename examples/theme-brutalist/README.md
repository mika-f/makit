# Brutalist theme example

A Makit site using the official brutalist theme.

```bash
pnpm install
pnpm --filter makit-example-theme-brutalist dev
```

## What to look at

| Where             | What it shows                                     |
| ----------------- | ------------------------------------------------- |
| Header            | Heavy structural border and boxed project mark    |
| Sidebar           | Reversed active item with an offset signal shadow |
| Page title        | Oversized uppercase display treatment             |
| Article headings  | Thick ruled sections and highlight bars           |
| Table of contents | Boxed index with a visible heading count          |
| Background        | A subtle construction grid outside the article    |
