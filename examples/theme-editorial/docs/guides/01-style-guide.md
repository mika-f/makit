# Style guide

The editorial theme is intentionally restrained. Hierarchy comes from type,
spacing, and rules rather than shadows or colored containers.

## Headings

Headings use a serif display stack. Second-level headings begin a new section
with a fine rule, making long pages easy to navigate without turning every
section into a card.

### A third-level heading

Third-level headings are smaller but retain the display face. Body copy stays
at a comfortable measure and line height.

## Quotations

> Good documentation has a voice. The interface should make room for it.

Blockquotes use a single hairline and italic text, echoing a printed pull quote.

## Tables

Tables return to the sans-serif interface face for dense data.

| Element       | Typeface | Purpose                |
| ------------- | -------- | ---------------------- |
| Page titles   | Serif    | Establish the article  |
| Body copy     | Serif    | Sustained reading      |
| Navigation    | Sans     | Fast scanning          |
| Code and data | Mono     | Precise interpretation |
