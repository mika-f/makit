# Editorial theme example

A Makit site using the official editorial theme.

```bash
pnpm install
pnpm --filter makit-example-theme-editorial dev
```

The site contains only configuration and Markdown. The page shell comes from
`theme.extends`.

## What to look at

| Where             | What it shows                                      |
| ----------------- | -------------------------------------------------- |
| Header            | A compact masthead with publication-style mark     |
| Page title        | Serif display type and a section kicker            |
| Sidebar           | Ruled active state instead of cards or pills       |
| Article body      | A narrow, book-like serif reading column           |
| Table of contents | Marginalia treatment with a single active hairline |
